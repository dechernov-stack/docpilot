# DocPilot — исполненный тестовый срез

Источник требований: `TZ_DocPilot.md`, переданный пользователем 06.09.2026.

Этот репозиторий реализует проверяемый P0-срез: четыре раздела ConOps, шесть видов элементов, MCR/SRR-полноту, `.sdoc`, Git baseline/diff, STUB-рендеринг, числовой guard, рецензию и выпуск. Подробная матрица возможностей, 10-минутный тур и честные ограничения приведены в `README.md`; исполняемые критерии — в `backend/tests/test_acceptance.py` и `e2e/tests/docpilot-tour.spec.ts`.
